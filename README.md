# Echo Podcast Clone

A professional, fully responsive, pixel-perfect frontend clone of **Echo Podcast**, built as part of a senior engineering internship evaluation.

---

## Features

- **Semantic HTML5 & Modern CSS3:** Clean, modular, and fully compliant with web standards.
- **Bootstrap 5 Integration:** Utilizes Bootstrap's grid and utilities combined with custom styling for precise design replication.
- **Dark Mode Support:** Built-in theme toggling stored via `localStorage` for persistent user preferences.
- **Interactive Search Overlay:** Real-time search filter for episodes, hosts, and categories.
- **Scroll Progress Indicator:** Dynamic top progress bar indicating reading/scrolling depth.
- **Back to Top Button:** Smooth scroll utility appearing upon scrolling down.
- **Fully Responsive:** Optimized layouts for Desktop, Laptop, Tablet, and Mobile devices.
